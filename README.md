# Практика навчальна 3

**Практика з web-програмування** для спеціальності 121 «Інженерія програмного забезпечення».

[Робоча програма 2026 року](<РПНД Практика навчальна 3 121 2026.docx>) передбачає 225 годин (150 практичних і 75 самостійних), 7,5 кредитів ЄКТС і залік із захистом звіту.

Матеріали семи етапів збережено за каталогами `week-01` – `week-07`. Розподіл годин за етапами наведено в робочій програмі.
